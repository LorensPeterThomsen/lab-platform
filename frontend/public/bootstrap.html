Bootstrap: opret første admin for et lab

Vigtigt
  • Bootstrap-token er typisk engangs og kan udløbe.
  • Token skal udleveres sikkert af leverandøren.
  • Når første admin er oprettet, skal resten oprettes via admin-panelet.
Det tekniske lab-id (fx lab-q), ikke et visningsnavn.
Token er base64url (ligner lange tegn/underscore/bindestreg). 
Udfyld felter og tryk “Opret første admin”.
Efter success:
  1. Gå til hovedsiden og log ind med admin-brugeren.
  2. Åbn Admin-siden og opret de øvrige brugere i lab’et.
